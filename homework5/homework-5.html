Homework 5: Integration and the normal CDF

Compare domain partitions with range partitions, then build a numerical standard-normal CDF.

Exercise 1 — Riemann and Lebesgue integration

A Riemann sum partitions the domain into small intervals. In this experiment we use midpoint samples:

Rn = ∑i=1n f((xi-1 + xi)/2)(xi - xi-1).

A Lebesgue-style finite approximation partitions the range into value bins. We sample the domain to estimate the measure of each preimage and multiply that measure by the bin midpoint:

Lm,N = ∑j=1m yj* · λ({x : f(x) is in range bin j}).

The second method is still numerical: the preimage measures are estimated from N equally spaced domain probes. It is therefore a range-partition implementation of the Lebesgue idea, not an exact symbolic measurement of every preimage.

What the examples show

For continuous functions such as sin(x), x², |x - 0.5| and the removable-continuity function sin(x)/x (where its value at zero is defined as 1), both constructions converge to the same integral. The range method can be less accurate at a fixed budget because quantizing function values adds a second discretization error.

Jump functions are Riemann-integrable because their discontinuities have measure zero. They are also natural Lebesgue examples: the preimages of the two values are intervals whose measures can be estimated directly. The improper integral of 1/√x is finite and equals 2, but the endpoint is singular, so truncation and a suitable quadrature rule are important.

Pathological caution. The Dirichlet function is 1 on rationals and 0 on irrationals. It is not Riemann-integrable, while its Lebesgue integral is 0 because the rationals have measure zero. A floating-point grid contains only one kind of representation and cannot test rationality; this page therefore reports the literal sampled-grid behavior and explains why it is not evidence about the exact function. Thomae’s function is Riemann-integrable with integral 0, and a range method usually sees its small rational values disappear as resolution increases.

Exercise 2 — Numerical computation of the normal CDF

For a standard normal random variable Z, the CDF is

Φ(z) = (1/√(2π)) ∫-∞z e-t²/2 dt = ½[1 + erf(z/√2)].

There is no elementary antiderivative for e-t². Liouville’s theorem on elementary antiderivatives implies that an elementary antiderivative would require a rational-function correction multiplying e-t²; solving the resulting differential equation would require a rational function that does not exist. The error function is introduced precisely to name this non-elementary integral.

Special-function notation gives an exact analytical representation, but software still has to evaluate erf numerically. Below, Simpson integration, the erf power series, and a standard erf approximation are compared against trusted reference values. The approximation is useful in production because it is fast and has a small, controlled error; the series makes the analytical connection visible.

Conclusion

Riemann sums are often the simplest choice for a smooth function because domain samples are straightforward and convergence is easy to visualize. A Lebesgue-style range partition groups points with similar values and can be advantageous for simple-valued functions or when preimage measures are easy to calculate, but numerical range quantization introduces its own error. For every Riemann-integrable example above, both methods target the same integral; for Dirichlet’s function, the exact Lebesgue/Riemann distinction cannot be recovered from a naive floating-point grid.

For the normal CDF, numerical integration is conceptually direct, while erf-based methods are faster and more stable for repeated evaluation. None of these numerical procedures contradicts the non-elementary nature of the antiderivative: they are algorithms for evaluating a special function whose defining integral has no elementary closed form.
