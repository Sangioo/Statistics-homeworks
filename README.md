# Statistics-homeworks

Progetto didattico diviso in due pagine, raggiungibili dalla pagina iniziale `index.html`:

- `homework-1.html` — moltiplicazione scalare su una curva ellittica giocattolo e analisi statistica.
- `homework-2.html` — pipeline dal seed del wallet all’indirizzo Ethereum, con riferimenti.

`style.css` contiene gli stili condivisi; `script.js` gestisce l’interazione del primo homework.
