Exercise 1 — Welford’s recurrence formulas

We want to update the mean and variance when one new observation arrives, using only the previous count, mean and sum of squares. Let x₁, …, xₙ be the observations collected so far.

Notation used throughout this homework: μ denotes the theoretical population mean; μₙ = (1/n)∑ᵢ₌₁ⁿ xᵢ denotes the sample mean after n observations. For hacker j, this becomes μⱼ,ₙ. The average of the m hackers’ sample means is μ̄ₙ = (1/m)∑ⱼ₌₁ᵐ μⱼ,ₙ. A subscript therefore distinguishes an estimated mean from the population mean μ.

Define the centered sum of squares SSₙ = ∑ᵢ₌₁ⁿ(xᵢ − μₙ)². The descriptive variance is vₙ = SSₙ/n; the unbiased sample variance is sₙ² = SSₙ/(n − 1), defined for n ≥ 2. In Exercise 2, “sample variance” always means sₙ², which estimates the population variance σ².

1. Recover the recurrence for the mean

For n ≥ 2, assume we already know μₙ₋₁. By its definition, the sum of the first n − 1 observations is ∑ᵢ₌₁ⁿ⁻¹ xᵢ = (n − 1)μₙ₋₁. Separate the new value xₙ from that sum:

μₙ = [∑ᵢ₌₁ⁿ⁻¹ xᵢ + xₙ]/n
= [(n − 1)μₙ₋₁ + xₙ]/n
= [nμₙ₋₁ + (xₙ − μₙ₋₁)]/n
= μₙ₋₁ + (xₙ − μₙ₋₁)/n.

Write δₙ = xₙ − μₙ₋₁ for the distance of the new observation from the old mean. Knuth’s recurrence is then μₙ = μₙ₋₁ + δₙ/n: the mean moves by 1/n of that distance. We will use these two consequences:

Mean shift: μₙ − μₙ₋₁ = δₙ/n.
New residual: xₙ − μₙ = xₙ − (μₙ₋₁ + δₙ/n)
= δₙ − δₙ/n = [(n − 1)/n]δₙ.

2. Account for the change in every old residual

We cannot obtain SSₙ just by adding the new squared residual to SSₙ₋₁: the first n − 1 observations must also be measured relative to the new mean μₙ. For each old observation, add and subtract μₙ₋₁:

xᵢ − μₙ = (xᵢ − μₙ₋₁) − (μₙ − μₙ₋₁)
= (xᵢ − μₙ₋₁) − δₙ/n, for i = 1, …, n − 1.

Now separate the new observation in the definition of SSₙ and use (a − b)² = a² − 2ab + b² on each old residual:

SSₙ = ∑ᵢ₌₁ⁿ⁻¹(xᵢ − μₙ)² + (xₙ − μₙ)²
= ∑ᵢ₌₁ⁿ⁻¹[(xᵢ − μₙ₋₁) − δₙ/n]² + (xₙ − μₙ)²
= ∑ᵢ₌₁ⁿ⁻¹(xᵢ − μₙ₋₁)²
− (2δₙ/n)∑ᵢ₌₁ⁿ⁻¹(xᵢ − μₙ₋₁)
+ (n − 1)δₙ²/n² + (xₙ − μₙ)².

The first sum is exactly SSₙ₋₁. The constant δₙ²/n² appears once for each of the n − 1 old observations, which explains its multiplier. The cross term vanishes because deviations from their own mean sum to zero:

∑ᵢ₌₁ⁿ⁻¹(xᵢ − μₙ₋₁)
= ∑ᵢ₌₁ⁿ⁻¹xᵢ − (n − 1)μₙ₋₁
= (n − 1)μₙ₋₁ − (n − 1)μₙ₋₁ = 0.

3. Simplify to Welford’s SS recurrence

Substitute the new residual xₙ − μₙ = [(n − 1)/n]δₙ from step 1 and combine the two remaining correction terms:

SSₙ = SSₙ₋₁ + (n − 1)δₙ²/n² + (n − 1)²δₙ²/n²
= SSₙ₋₁ + [(n − 1) + (n − 1)²]δₙ²/n²
= SSₙ₋₁ + [n(n − 1)/n²]δₙ²
= SSₙ₋₁ + [(n − 1)/n]δₙ².

Finally, one factor δₙ is xₙ − μₙ₋₁, and the other factor [(n − 1)/n]δₙ is xₙ − μₙ. This gives the form used in the code:

SSₙ = SSₙ₋₁ + (xₙ − μₙ₋₁)(xₙ − μₙ).

The product uses the distance from the old mean and the distance from the new mean. Thus the update needs only the previous SS, the previous mean, the new score and the count.

4. Obtain the descriptive variance recurrence

Since vₙ = SSₙ/n and vₙ₋₁ = SSₙ₋₁/(n − 1), replace SSₙ₋₁ by (n − 1)vₙ₋₁ and divide the SS recurrence by n:

vₙ = [SSₙ₋₁ + ((n − 1)/n)δₙ²]/n
= [(n − 1)vₙ₋₁]/n + [(n − 1)/n²]δₙ²
= [(n − 1)/n]vₙ₋₁ + [(n − 1)/n²]δₙ², for n ≥ 2.

5. Obtain the unbiased sample variance recurrence

Now use sₙ² = SSₙ/(n − 1). The previous sample contains n − 1 observations, so its sample-variance denominator is (n − 1) − 1 = n − 2. Therefore SSₙ₋₁ = (n − 2)sₙ₋₁². Substitute this identity and divide the SS recurrence by n − 1:

sₙ² = [SSₙ₋₁ + ((n − 1)/n)δₙ²]/(n − 1)
= [(n − 2)sₙ₋₁²]/(n − 1) + [(n − 1)δₙ²]/[n(n − 1)]
= [(n − 2)/(n − 1)]sₙ₋₁² + δₙ²/n, for n ≥ 3.

The correction term simplifies to δₙ²/n because the factor n − 1 cancels. This recurrence starts at n = 3 because s₁² is undefined. Dividing the updated SS directly by n − 1 works from n = 2 onward.

6. Initialize and implement in three lines

For the first observation, μ₁ = x₁ and SS₁ = v₁ = 0. At n = 2, δ₂ = x₂ − x₁, so SS₂ = δ₂²/2 and s₂² = SS₂/(2 − 1) = (x₂ − x₁)²/2.

In code, initialize state = { n: 0, mu: 0, ss: 0 }. Here mu represents the running mean μₙ; its initial zero is a placeholder before any observations arrive. For each new score x, the same function used by the experiment performs:

const delta = x - state.mu;
state.mu += delta / ++state.n;
state.ss += delta * (x - state.mu);

The first line computes δₙ using the old mean. The second increments the count to n and computes μₙ. The third updates SS using the old residual saved in delta and the new residual x - state.mu. On the very first update, the mean becomes x₁ and the new residual is zero, so SS remains zero as required.

After the update, use state.ss / state.n for vₙ, or state.n > 1 ? state.ss / (state.n - 1) : null for sₙ². Each observation requires constant memory and constant work. Updating centered deviations also avoids subtracting two potentially large, nearly equal quantities in ∑xᵢ² − nμₙ².

Worked check with scores 2, 4, 6: after the first score, μ₁ = 2 and SS₁ = 0. For x₂ = 4, δ₂ = 4 − 2 = 2, μ₂ = 2 + 2/2 = 3, and SS₂ = 0 + 2(4 − 3) = 2. For x₃ = 6, δ₃ = 6 − 3 = 3, μ₃ = 3 + 3/3 = 4, and SS₃ = 2 + 3(6 − 4) = 8. Hence v₃ = 8/3 and s₃² = 8/2 = 4. Directly, (2 − 4)² + (4 − 4)² + (6 − 4)² = 8, confirming SS₃.

Exercise 2 — Scored penetration attempts

There are m hackers and n systems. Each hacker j receives one score Xⱼ,ᵢ for each system i. Scores are modeled as independent and identically distributed, both within and between hackers, with a fixed discrete uniform distribution on {0, 1, …, 10}. Each integer has probability 1/11. This extends the previous homework from a binary success indicator to a graded score.

μ = E[X] = (0 + 1 + … + 10)/11 = 5.
E[X²] = 385/11 = 35, so σ² = E[X²] − μ² = 10.

For each hacker, Welford’s update computes μⱼ,ₙ and sⱼ,ₙ² = SSⱼ,ₙ/(n − 1). Across all m hackers, we calculate the average mean μ̄ₙ = (1/m)∑ⱼ μⱼ,ₙ and the average sample variance Bₙ = (1/m)∑ⱼ sⱼ,ₙ². We compare μ̄ₙ with μ = 5 and Bₙ with σ² = 10, then use the trajectories and histograms to observe how the estimates become more concentrated as n increases.

Why the averages recover μ and σ²

Each hacker’s sample mean and sample variance are unbiased: over repeated random samples, their expected values equal the population mean and variance. Here E[·] denotes this theoretical average.

E[μⱼ,ₙ] = (E[Xⱼ,₁] + … + E[Xⱼ,ₙ])/n = nμ/n = μ = 5.
E[sⱼ,ₙ²] = E[SSⱼ,ₙ]/(n − 1) = (n − 1)σ²/(n − 1) = σ² = 10.

The denominator n − 1 corrects for measuring deviations from the sample’s own estimated mean: E[SSⱼ,ₙ] = (n − 1)σ². Dividing by n would underestimate σ² on average.

When we average these estimates across independent hackers, random errors tend to cancel. By the Law of Large Numbers, as m grows, μ̄ₙ approaches 5 and Bₙ approaches 10, even with a fixed n ≥ 2. A finite experiment usually gives values close to these targets, rather than exact equality.

Increasing m makes the averages across hackers more stable; increasing n makes each hacker’s own estimates more precise.

What changes when the number of systems increases?

As n increases, each estimate uses more observations: the sample means become concentrated around μ = 5, and the sample variances become concentrated around σ² = 10. Both μₙ and sₙ² are consistent estimators: with more observations they concentrate around the population mean and variance. This does not mean that every trajectory or average gets closer to its target at every step. For example, the recorded average sample variance moves slightly farther from 10 between n = 10 and n = 100 before becoming closer at n = 1,000.

Increasing m averages over more independent hackers and makes the experimental comparison more stable. Increasing n improves each hacker’s estimate. The variability of the individual scores themselves remains σ² = 10; it is the estimates that become more stable. Unbiasedness describes the correct target on average, even at small n, while greater precision requires enough observations.

Why this matters in inferential statistics

In real data, μ and σ² are usually unknown. A sample mean estimates the population mean, and the unbiased sample variance estimates the unknown population variance. The simulation lets us see their repeated-sampling behavior against known targets: bias describes where estimates are centered, while sampling variability describes their precision.

For large n, the Central Limit Theorem and consistency of sₙ² justify an approximate 95% confidence interval μₙ ± 1.96 √(sₙ²/n) for μ. Across repeated independent samples, about 95% of intervals constructed this way cover the fixed population mean, asymptotically. The standard error is sₙ/√n, not sₙ². These uncertainty estimates support confidence intervals, hypothesis tests and sample-size planning; roughly quadrupling n halves the standard error.

The uniform scores here are not normally distributed, so small-sample normal, exact Student-t, or exact chi-square variance inference is not automatically justified. The conclusions depend on the stated independence and common-distribution assumptions; correlated penetration attempts would change the sampling variability.
